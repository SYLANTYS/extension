# Options Chains Chrome Extension

This project is a Chrome extension built with **React**, **TypeScript** and **Vite**. The extension lets you quickly fetch option chain data for a stock ticker and view short company summaries generated by OpenAI. Option data and price charts are loaded from the Yahoo Finance API.

The UI is written in React and compiled with Vite. Background and content scripts interact with the browser to automatically request data when you search for a ticker on Google.

## Features

- Search for a ticker and fetch call/put options from Yahoo Finance.
- Short AI‑generated company summary using OpenAI.
- View option details and interactive charts for selected contracts.
- Data is stored in `chrome.storage` so it persists between popup openings.

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Create an `.env` file** in the project root and provide API keys (see [Environment variables](#environment-variables)).
3. **Build the extension**
   ```bash
   npm run build
   ```
   The compiled extension will be output to the `dist/` directory along with the files from `public/`.
4. **Load in Chrome**
   - Open `chrome://extensions/` in your browser.
   - Enable _Developer mode_.
   - Click **Load unpacked** and choose the `dist` folder.

During development you can run `npm run dev` to preview the React interface in the browser, but the extension itself must be loaded via the steps above.

## Environment variables

The extension requires the following environment variables at build time:

- `VITE_OPENAI_API_KEY` – OpenAI API key used to generate company summaries.
- `VITE_YAHOO_FINANCE_API_KEY` – Yahoo Finance API key used for option chains and chart data.

Create a file named `.env` and supply the keys, e.g.

```bash
VITE_OPENAI_API_KEY=your-openai-key
VITE_YAHOO_FINANCE_API_KEY=your-yahoo-finance-key
```

These values are embedded into the scripts when running `npm run build`.

## Repository structure

- `src/` – React source code for the popup UI and chart components.
- `public/` – manifest, background script and content script for the Chrome extension.
- `dist/` – generated after running the build command; load this folder when installing the extension.
